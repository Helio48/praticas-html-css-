## 🚀 Projetos desenvolvidos

### 📁 01 — Página de Perfil
Minha primeira página pessoal utilizando HTML5.

**Conhecimentos praticados:**
- Estrutura básica do HTML.
- Títulos e parágrafos.
- Listas.
- Links e imagens.

### 📁 02 — Página de Cursos
Página para apresentar cursos e conteúdos de estudo.

**Conhecimentos praticados:**
- Organização de informações.
- Listas e tabelas.
- Estruturação de conteúdo HTML.

### 📁 03 — DevStart 2026
Página de divulgação de um evento fictício de tecnologia.

**Conhecimentos praticados:**
- Estruturação de páginas.
- Formulários HTML.
- Tabelas e links.
- Organização de conteúdos.

### 📁 04 — Minha Biblioteca Dev
Página dedicada à organização dos meus estudos, com recursos de programação e acompanhamento do progresso.

**Conhecimentos praticados:**
- Classes e IDs.
- CSS externo.
- Fontes personalizadas.
- Unidades de medida.
- Links e navegação entre páginas.

### 📁 05 — Café & Código
Desenvolvimento de um cardápio digital fictício, apresentando produtos, preços e horários de funcionamento.

**Conhecimentos praticados:**
- Listas HTML.
- Tabelas.
- Estilização com CSS.
- Bordas e espaçamentos.
- Fontes personalizadas.

### 📁 06 — DevAcademy
Portal fictício de cursos de tecnologia, com página principal, portal do aluno e ouvidoria.

**Conhecimentos praticados:**
- Classes e IDs.
- Formulários HTML.
- Tabelas.
- Navegação entre páginas.
- CSS externo.
- Box Model.
- Unidades de medida (`px`, `%`, `em` e `rem`).
