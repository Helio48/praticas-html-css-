##  Semana 3 — HTML e CSS

Nesta semana, aprofundei meus conhecimentos em HTML e CSS,
trabalhando com imagens de fundo, seletores CSS, classes, IDs,
pseudo-classes, pseudo-elementos, herança e especificidade.

Desenvolvi três projetos para colocar esses conceitos em prática.

###  07 — Portfólio Ana Bella

Projeto desenvolvido durante as aulas do curso de Desenvolvimento Web.

O objetivo foi construir um portfólio fictício para uma modelo,
utilizando diferentes páginas HTML e um arquivo CSS compartilhado.

**Conceitos praticados:**
- Estruturação de páginas HTML.
- Navegação entre páginas.
- Imagens e imagens de fundo.
- Seletores CSS.
- Estilização de menus.
- Pseudo-classe `:hover`.
- Organização e reutilização de estilos.

###  08 — Cartão de Perfil Interativo

Projeto prático de uma página de apresentação profissional fictícia.

A página apresenta informações sobre um desenvolvedor Full Stack,
suas experiências profissionais e links para seus trabalhos.

**Conceitos praticados:**
- Estruturação de conteúdo com HTML.
- Listas não ordenadas.
- Imagens de fundo.
- Seletores por ID.
- Estilização de links.
- Pseudo-classe `:hover`.
- Pseudo-elemento `::first-letter`.

###  09 — Página de Vagas Tech

Projeto prático de uma página fictícia de oportunidades
de emprego na área de tecnologia.

A página apresenta quatro vagas, informações sobre empresas,
modalidades de trabalho, requisitos e um formulário para
cadastro no banco de talentos.

**Conceitos praticados:**
- Estruturação de páginas HTML.
- Classes CSS reutilizáveis.
- Organização de conteúdo com `div`.
- Imagens e estilização de elementos.
- Formulários HTML.
- Pseudo-classes `:hover`, `:active` e `:focus`.
- Seletor `:required`.
- Bordas, espaçamentos e personalização visual.

**Observação:** Os projetos foram desenvolvidos para fins
educacionais, utilizando HTML e CSS.
