#  Práticas de HTML e CSS

Olá! Seja bem-vindo ao meu repositório de estudos.

Sou estudante de Análise e Desenvolvimento de Sistemas (ADS)
e estou iniciando minha jornada no Desenvolvimento Full Stack.

Este repositório foi criado para registrar minha evolução
nos estudos de HTML5 e CSS3, por meio de exercícios práticos.

##  Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Exercícios desenvolvidos

### 01 - Perfil Pessoal
Página de apresentação pessoal utilizando elementos básicos
do HTML5 e estilização com CSS3.

### 02 - Página de Cursos
Página contendo uma tabela de cursos, links e estilizações
utilizando CSS3.

### 03 - DevStart 2026
Site fictício de um evento de tecnologia.

O projeto contém:
- Página principal do evento;
- Programação organizada em tabela;
- Formulário de inscrição;
- Páginas sobre workshops, minicursos e palestras;
- Navegação entre páginas.

##  Objetivo

Praticar os conhecimentos adquiridos durante meus estudos,
desenvolver autonomia na programação e acompanhar minha
evolução como futuro desenvolvedor Full Stack.

Novos exercícios serão adicionados conforme meu aprendizado
em novas tecnologias.
